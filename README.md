# Gamificador de Rotina

Projeto desenvolvido na disciplina de Desenvolvimento Web.

## Objetivo

Desenvolver um sistema Web para cadastrar e acompanhar
tarefas rotineiras, incentivando a criacao de habitos
por meio de sequencias de realizacao (streaks).

## Tecnologias

- React
- Next.js
- TypeScript
- Tailwind CSS
- Git e GitHub
- Vercel para publicacao

## Como executar

1. Instalar Node.js.
2. Clonar o repositorio.
3. Acessar a pasta gamificador-de-rotina.
4. Executar os comandos:

    npm install
    npm run dev

5. Acessar https://gamificador-de-rotina.vercel.app/ no navegador.
   Se a porta estiver ocupada, utilizar a porta
   informada pelo terminal.

## Funcionalidades planejadas

- Login e cadastro de usuarios
- Cadastro e edicao de tarefas
- Tarefas diarias, semanais e mensais
- Registro de atividades realizadas
- Contagem de streaks
- Busca e filtros de tarefas
- Layout responsivo

## Divisao do grupo

Pessoa 1: base, infraestrutura, documentacao e deploy.
Pessoa 2: login e cadastro de usuarios.
Pessoa 3: tela principal e interacoes.
Pessoa 4: formulario de tarefas e API REST.
Pessoa 5: streaks, testes e acessibilidade.

## Versionamento

Cada integrante desenvolve suas funcionalidades
em uma branch propria.

As alteracoes sao registradas por commits e
integradas a main por meio de Pull Requests.
